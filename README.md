# Lord Beauty — página de links

Landing page estática responsiva para GitHub Pages.

## Antes de publicar

Abra `config.js` e cole o convite real do grupo WhatsApp no campo `whatsapp`.
O campo `telegram` veio preenchido com o canal geral `https://t.me/LordOfertasVip`, conforme informado anteriormente. Troque-o caso seja outro canal.
Você pode deixar `instagram` vazio.

**IMPORTANTE:** Sem o link de WhatsApp configurado, o botão principal exibe um aviso e NÃO abre um grupo.

## Publicação no GitHub sem instalar programas

1. Acesse https://github.com e entre na sua conta.
2. Clique em **New repository**; nomeie `lord-beauty`; escolha **Public**; crie o repositório.
3. Dentro dele, clique em **Add file > Upload files**.
4. Envie **os arquivos e a pasta assets que estão dentro deste ZIP**, sem criar uma pasta externa `lord-beauty-site` dentro do repositório.
5. Confirme em **Commit changes**.
6. Vá em **Settings > Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main** e pasta **/(root)**. Clique **Save**.
8. Aguarde alguns minutos; o site terá a URL `https://SEU-USUARIO.github.io/lord-beauty/`.

Para editar os links depois, abra `config.js` no GitHub, clique no lápis (**Edit this file**), altere e clique em **Commit changes**. Aguarde a atualização.

## Observações

- O site não inclui rastreadores nem coleta de dados pessoais.
- Não coloque tokens, senhas ou dados privados no repositório público.
- Linktree pode ser substituído na bio pelo endereço público do GitHub Pages após a publicação.
- Os textos não prometem descontos percentuais não comprovados ou exclusividade inexistente.
